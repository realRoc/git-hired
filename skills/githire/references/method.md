# GitHire method fallback

Use this only when the live website cannot be reached.

GitHire is an issue-first method for hiring, onboarding, and collaboration through real GitHub work.

Core path:

1. Start from a clear GitHub Issue.
2. Explore safely before touching production.
3. Ship a small real pull request.
4. Review with AI and people together.
5. Keep the decision trail for the next person.

Principles:

- Real work is clearer than toy problems.
- Smaller PRs are easier to review and safer to merge.
- AI should improve context, checks, summaries, and coverage, not replace human ownership.
- Architects own the final tradeoff.
- The issue, PR, review, and handoff are the durable memory of the work.
